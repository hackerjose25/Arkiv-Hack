# Three-minute demo recording script

Record only after the release checklist's real seed, dashboard publication, public access and independent embed pass. Do not use RPC fixtures for the submitted demonstration. Keep wallet recovery information and unrelated browser tabs out of the recording. This script is prepared; no video has been recorded.

| Time | Show | Narration |
|---|---|---|
| 0:00–0:20 | Public studio and source link | “ArkivSight turns public Arkiv entities into dashboards without writing a frontend. It is an MIT tool that other Arkiv developers can reuse.” |
| 0:20–0:45 | Actual seeded rows, default query plus real `$creator` filter | “These fictional demo metrics are real Tiramisu entities. Filters operate on typed indexed attributes. Creator and owner come from Arkiv metadata, not user-written claims.” |
| 0:45–1:10 | Category sum chart, then KPI | “This chart totals the current result page. The table, charts and pagination share a pinned query snapshot. Payload JSON is inspected separately; it is not treated as indexed data.” |
| 1:10–1:40 | Dashboard composition, wallet-approved publication or the actual confirmed receipt | “The wallet signs a versioned dashboard definition with an approximately 90-day lifetime. The app reads it back and shows the real transaction and entity key. Source records use a separate 30-day lifetime.” |
| 1:40–2:05 | Public URL in a wallet-free browser | “This browser reads the definition by entity key and queries Arkiv directly. Refresh uses modest polling, pauses in hidden tabs and backs off on failure.” |
| 2:05–2:30 | Consumer page on another origin | “The same dashboard loads in another website through the documented iframe interface. Viewers need no wallet or private backend account.” |
| 2:30–2:55 | MIT repository, schema and friction files | “The source and JSON contract are reusable. Our friction report records actual network and SDK experiments. Arkiv makes these public definitions and their provenance independently readable.” |
| 2:55–3:00 | Live link and repo | “ArkivSight: query, understand and share public Arkiv data.” |

Before uploading, check duration, legible text, working public links, correct writer address, real transaction/key evidence and absence of personal information. Use the confirmed receipt if a signature would exceed the time budget; do not pretend a pre-recorded confirmation is a new transaction.
